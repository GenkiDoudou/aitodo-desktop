# 自动更新手工验收清单

在真实打包产物与已上传的 GitHub Release 上勾选：

- [ ] **免解压 + 同级 `data/`**：旧版目录旁有任务数据；检查更新 → 下载 → 重启后版本升高且任务仍在
- [ ] **自定义数据目录**：设置里改过数据路径后更新；路径与数据不变
- [ ] **GitHub 更新源**：检查更新能拉到 `latest.yml` / 安装包并完成升级
- [ ] **NSIS**：安装版检查更新 → 下载 → 「重启以更新」后进入新版本
- [ ] **macOS**：zip 安装用户同样走 `quitAndInstall` 成功
- [ ] **开发模式**：`npm run dev` 下自动检查不下载线上包；设置里手动检查提示开发模式
- [ ] **无签名提示**：文档/关于页说明存在；被系统拦截时应用仍可用旧版
