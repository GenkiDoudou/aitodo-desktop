# 桌面端页面清单（重设计参考）

> 面向 UI/UX 重设计：按**用户可见的页面/屏幕**统计，说明每页做什么、有哪些字段、有哪些操作。  
> 技术实现见文末「路由与组件映射」。

---

## 使用说明

- **页面**：用户能独立感知的界面（含侧栏弹层、独立窗口）；不等同于 Vue 路由数（路由仅 3 个，页面远多于 3 个）。
- **展示字段**：列表/卡片/日历格子上**只读出现**的信息。
- **编辑字段**：表单里可修改并保存的数据。
- **任务**是核心实体，多页共用同一套字段，差异在「展示哪些」「能改哪些」。

---

## 一、核心数据字段速查

重设计时建议先统一「任务 / 清单」字段词典，各页引用同一套。

### 1.1 任务 Task

| 字段 | 类型/取值 | 说明 | 常见出现页面 |
|------|-----------|------|--------------|
| `title` | 文本 | 标题 | 列表、详情、看板、日历、收件箱 |
| `description` | 富文本/Markdown | 正文、可含附件链接 | 详情 |
| `status` | `TODO` / `IN_PROGRESS` / `DONE` | 状态 | 列表勾选、详情、看板列 |
| `priority` | `1`–`4`（P0–P3） | 优先级；4=无优先级 | 列表徽章、详情、四象限 |
| `categoryId` | 清单 ID / null | 所属清单 | 列表 meta、详情、筛选 |
| `parentId` | 任务 ID / null | 父任务；有值则为子任务 | 列表树形、详情子任务区 |
| `tags` | 字符串数组 | 标签 | 详情 |
| `dueAt` | 日期时间 | 截止时间 | 列表、详情、日历、时间轴 |
| `startAt` | 日期时间 | 计划开始（时间轴条带起点） | 时间轴 |
| `remindAt` | 日期时间 | 主提醒时间（兼容单条） | 列表 meta |
| `reminders` | 数组 | 多条提醒（偏移分钟 + 绝对时间） | 详情 |
| `remindContinuous` | 布尔 | 持续提醒直至处理 | 详情 |
| `recurrence` | 规则对象 | 重复：每天/每周/工作日/自定义间隔等 | 详情、日历 occurrence |
| `completedAt` | 日期时间 | 完成时间 | 已完成列表、列表 meta |
| `createdAt` | 日期时间 | 创建时间 | 列表 meta |
| `kanbanGroupId` | 分组 ID / null | 看板自定义列 | 看板 |
| `sortOrder` | 数字 | 同层排序 | 列表拖拽（不直接展示） |
| `triagedAt` | 时间 / null | 是否已排优；null 进收件箱 | 收件箱逻辑 |
| `deletedAt` | 时间 / null | 软删除时间 | 垃圾桶 |
| `completedOccurrenceDates` | 日期数组 | 重复任务某日已完成 | 日历 |

### 1.2 清单 Category

| 字段 | 说明 | 出现页面 |
|------|------|----------|
| `name` | 清单名称 | 侧栏、列表 meta、详情下拉 |
| `color` | 色点 | 侧栏、列表、日历 |
| `keywords` | 关键词数组 | 清单编辑、自动归类 |
| `sortOrder` | 侧栏排序 | 侧栏拖拽 |

### 1.3 便签 WidgetNote（挂件/收件箱）

| 字段 | 说明 |
|------|------|
| `content` | 正文 |
| `color` | 便签颜色 |
| `pinned` | 是否置顶 |

## 二、页面清单

### 页面 1：任务列表页（主列表）

**入口**：侧栏「全部」/「最近 7 天」/ 某清单 / 某自定义视图  
**组件**：`HomeView` + `TaskList`（或看板/时间轴，见页面 2、3）  
**用途**：浏览、筛选、分组、排序任务；快捷新建；点击进入详情。

#### 页面结构

```
┌──────────┬────────────────────────────────────┬─────────────┐
│ 侧栏导航  │ 顶栏：标题 + 计数 + 筛选控件          │             │
│          ├────────────────────────────────────┤  任务详情    │
│          │ 快捷添加框（部分视图隐藏）            │  （页面 8）  │
│          ├────────────────────────────────────┤             │
│          │ 任务列表 / 分组标题 / 树形子任务      │             │
└──────────┴────────────────────────────────────┴─────────────┘
```

#### 顶栏展示与控件

| 区域 | 内容 |
|------|------|
| 标题 | 当前视图名：全部 / 清单名 / 视图名 / 最近 7 天… |
| 计数 | `(未完成数/总数)`，特殊视图可能隐藏 |
| 日期字段 | 「最近 7 天」等：下拉选 `截止/创建/完成` |
| 列表设置 | 齿轮菜单 `TaskListViewMenu`（见下） |
| 快捷添加 | 输入框 + 优先级旗（非收件箱/四象限/已完成/垃圾桶时显示） |

#### 列表设置（筛选/布局，非任务字段）

| 配置项 | 可选值 |
|--------|--------|
| 展示模式 | 列表 / 看板 |
| 隐藏已完成 | 当前视图 / 全部 / 从不 |
| 启用分组 | 开/关 |
| 分组条件 | 时间 / 标签 / 优先级 / 状态 / 自定义 / 无 |
| 排序 | 自定义 / 时间 / 优先级 / 标题 / 标签 / 创建 / 完成 / 提醒 |
| 显示清单 | 多选清单（仅「全部」视图） |
| 列表时间字段显隐 | 创建 / 截止 / 提醒 / 完成（各开关） |

#### 自定义视图额外筛选（`filterRule` AST）

| 筛选字段 | 操作示例 |
|----------|----------|
| 清单 `category` | 属于某些清单 / 未分类 |
| 优先级 `priority` | 属于 P0–P3 |
| 状态 `status` | 属于 / 等于 / 不等于 |
| 截止 `dueAt` | 今天/本周/逾期/区间/为空… |
| 创建 `createdAt` | 同上 |
| 完成 `completedAt` | 同上 |
| 标题 `title` | 包含 / 不包含 |
| 有子任务 `hasSubtasks` | 是/否 |
| 有重复 `hasRecurrence` | 是/否 |
| 看板分组 `kanbanGroup` | 属于某列 |

#### 列表行展示字段（每条任务）

| 展示项 | 说明 |
|--------|------|
| 展开箭头 | 有子任务时 |
| 状态勾选 | 二态完成/未完成 |
| 优先级徽章 | P0–P3 |
| 标题 | 完成态删除线 |
| 子任务数量 | 折叠时显示 |
| Meta 行（可配置显隐） | 清单名、创建、截止、提醒、完成 |

#### 行内操作

| 操作 | 说明 |
|------|------|
| 点击行 | 打开详情侧栏 |
| 勾选 | 切换完成状态 |
| 右键 | 上移/下移（仅顶层） |
| 拖拽 | 调整顶层排序 |

### 页面 2：看板页

**入口**：列表设置切为「看板」，或自定义视图布局=看板  
**组件**：`TaskKanbanView`  
**用途**：按列管理任务，拖拽改状态/优先级/分组/时间/标签。

#### 看板列模式

| 模式 | 列含义 | 拖入效果 |
|------|--------|----------|
| 自定义分组 | 用户建的列 + 未分组 + 已完成 | 改 `kanbanGroupId` / 完成 |
| 状态 | 待办 / 进行中 / 已完成 | 改 `status` |
| 优先级 | P0–P3 + 无 | 改 `priority` |
| 时间 | 今天/明天/本周/无日期… | 改 `dueAt` |
| 标签 | 各标签一列 | 改 `tags` |

#### 卡片展示字段

| 字段 | 说明 |
|------|------|
| 状态勾选 | 同列表 |
| 标题 | |
| 子任务数 | |
| 描述摘要 | 正文前 48 字 |
| Meta | 清单、分组名、创建、截止（可配置） |

#### 列操作

| 操作 | 说明 |
|------|------|
| 点击列头 | 选中列 → 顶栏新建任务落入该列 |
| 列头 + | 在该列新建 |
| 自定义分组：列菜单 | 重命名、左右插入列、删除 |
| 拖拽卡片 | 跨列更新对应字段 |

### 页面 3：时间轴页

**入口**：自定义视图布局=时间轴（或列表设置中的时间轴模式）  
**组件**：`TaskTimelineView`  
**用途**：按日期横向查看任务跨度，拖拽改期。

#### 展示字段

| 区域 | 内容 |
|------|------|
| 表头 | 每日：日期数字 + 星期；今天/周末高亮 |
| 已排期行 | 优先级、标题、清单；彩色条带（`startAt`–`dueAt`） |
| 未排期区 | 无 `dueAt` 的任务列表 |

#### 操作

| 操作 | 说明 |
|------|------|
| 点击任务 | 打开详情 |
| 拖拽条带 | 改 `dueAt` / `startAt` |
| 双击空白格 | 在该日新建 |
| 点击某日表头 | 聚焦该日，其他变淡 |

### 页面 8：任务编辑 / 详情页

**入口**：列表/看板/日历/收件箱点击任务；`Ctrl+N` 新建  
**组件**：`TaskDetailPanel`（右侧侧栏或弹框）  
**用途**：查看和编辑单条任务的全部业务字段。

#### 页面结构

```
┌─────────────────────────────┐
│ 放大 │ 优先级 │ 关闭          │
├─────────────────────────────┤
│ Tab: 详情 | 动态              │
├─────────────────────────────┤
│ 标题（单行）                  │
│ 清单 · 状态 · 标签            │
│ 正文编辑器（Markdown/附件）    │
│ ▼ 安排（可折叠）              │
│   截止时间                    │
│   提醒（多条）                │
│   重复                        │
│ 子任务列表 + 添加             │
├─────────────────────────────┤
│ 删除 │ 取消 保存              │
└─────────────────────────────┘
```

#### 编辑字段一览

| 分组 | 字段 | 控件类型 |
|------|------|----------|
| 基础 | `title` | 单行输入 |
| 基础 | `description` | 富文本/Markdown 编辑器 |
| 基础 | `categoryId` | 清单下拉（色点+名称） |
| 基础 | `status` | 下拉：待办/进行中/已完成 |
| 基础 | `priority` | 头部旗帜菜单 P0–P3 |
| 基础 | `tags` | 标签多选/创建 |
| 安排 | `dueAt` | 快捷+月历+时间选择器 |
| 安排 | `reminders` | 多条：准时/提前5分/30分/1小时/自定义 |
| 安排 | `remindContinuous` | 持续提醒开关 |
| 安排 | `recurrence` | 每天/每周/每月/工作日/周末/法定节假日/自定义间隔 |
| 子任务 | 子任务 `title` + `status` | 列表勾选、行内删除、底部添加 |
| 附件 | 文件列表 | 打开/下载/删除（嵌在正文中） |

#### Tab：动态

| 展示 | 说明 |
|------|------|
| 变更记录列表 | 字段修改、状态变更等（需设置中开启记录） |

#### 底部操作

| 按钮 | 说明 |
|------|------|
| 删除 | 移入垃圾桶 |
| 取消 / 保存 | 关闭或提交 |
